# MultiThreaded Task Manager

A C# Console Application demonstrating **Asynchronous Programming** and the **Task Parallel Library (TPL)** in .NET.

## Features
- Concurrent data processing using `Parallel.ForEach`.
- Asynchronous task management using `async/await` and `Task.WhenAll`.
- Execution time measurement with `Stopwatch`.

## Technologies
- C# / .NET
- System.Threading.Tasks
